# Default Visible Columns (Core Columns)

## 1. Product

### Description
- Product name
- Thumbnail image

### Behavior
- hover to view.
- panel shows SKU breakdown:
  - SKU (size / color ...) quantities states
  - Quantity in stock
  - Units sold (period)
  - Sell-through %
  - Days of cover

---

## 2. Inventory Status (Smart Indicator)

### Description
Displays stock health using Days of Cover.

Days of Cover = Current Quantity / Average Daily Sales

### Display Format
- Numeric days value (e.g., "12 days")
- Color indicator:
  - Green: > 20 days
  - Yellow: 7–20 days
  - Red: < 7 days

### Tooltip
Shows:
- Total quantity
- Total inventory value (COGS × quantity)
- SKU breakdown with quantities

### Purpose
Helps identify low stock or overstock situations instantly.

---

## 3. Units Sold (Selected Period)

### Description
Total units sold within selected date range.

### Behavior
Sortable ascending/descending.

### Purpose
Quick ranking of product demand.

---

## 4. Revenue (Selected Period)

### Description
Total revenue generated by product in selected period.

### Behavior
Sortable.

### Purpose
Identify top revenue drivers.

---

## 5. Profit (Selected Period)

### Description
Gross profit generated in selected period.

Profit = Revenue − Cost of Goods Sold

### Display
- Profit value
- Margin % (optional secondary value)

### Behavior
Sortable.

### Purpose
Identify high-margin products.

---

## 6. Sell-Through %

### Description
Sell-Through % = Units Sold / (Units Sold + Current Stock)

Calculated within selected date range.

### Behavior
Sortable.

### Visual
Optional progress bar inside cell.

### Purpose
Measure product-market fit and turnover efficiency.

---

## 7. Days Since Last Sale

### Description
Number of days since last recorded sale.

### Display
- e.g., "2 days ago"
- If > 30 days, display warning icon.

### Purpose
Detect slow-moving or dead stock.

---

## 8. Stock Value (Current)

### Description
Current inventory value for the product.

Stock Value = Current Quantity × Cost of Goods Sold

### Behavior
Sortable.

### Purpose
Shows how much capital is tied up in each product.

---

## 9. Aging Band

### Description
Age of oldest inventory batch.

how old is the inventory by checking the oldest .creationTime on the skus on that product

if days < 30, we show the number of days, if not we show how many months + days (eg 2 months 23 days) (eg 2 months 23 days) (eg 2 months 23 days) (eg 2 months 23 days)

### Purpose
Identify seasonal or outdated inventory.

# Optional / Advanced Columns (Premium Tier)

## 11. Size Imbalance Indicator

### Description
Detects uneven stock distribution across sizes.

### Logic
Trigger warning if:
- One size > 50% of total stock
- Key sizes out of stock

### Display
Small warning icon.
Details visible in expanded SKU view.

### Purpose
Improve future buying decisions.

---
## 13. Discount Impact %

### Description
Percentage of sales made with discount applied.

Optional:
- Avg discount %
- Revenue lost to discounts

### Purpose
Monitor margin erosion.
